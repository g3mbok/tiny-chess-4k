A 4 KB Python chess engine: mailbox board, alpha-beta search with iterative deepening,
quiescence, transposition table, killers, history, null-move pruning, PVS and LMR,
plus a compact tapered positional evaluation.

## Run it

```sh
python main.py
```

The entry reads `MAKEFUN_ENV_URL` and speaks the make.fun game/move API.
